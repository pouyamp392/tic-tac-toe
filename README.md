# 🎮 Tic Tac Toe

A simple and interactive **Tic Tac Toe game** built with **HTML, CSS, and JavaScript**.

The game supports both **Single Player** and **Two Player** modes, with a customizable starting color and score tracking.

## ✨ Features

* 👤 **Single Player** — Play against the bot
* 👥 **Two Player** — Play with another person
* 🎨 Choose the starting color
* 🤖 Basic bot decision-making
* 🏆 Automatic win detection
* 🤝 Draw detection
* 📊 Score tracking
* 💾 Persistent scores and settings
* ⚙️ Game settings modal
* 🔄 Restart game

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript
* DOM API
* LocalStorage

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

Open the project folder and launch `index.html` in your browser.

That's it — no dependencies or build tools are required.
